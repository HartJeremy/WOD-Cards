# Card Deck WOD

A bodyweight workout app powered by a deck of cards.

## Classic Deck Defaults

♥ Hearts = Bicycle Crunches
♠ Spades = Plank Hold (seconds)
♦ Diamonds = Stairs
♣ Clubs = Jumps

### Face Cards

J = 10 Burpees
Q = 20 Push-ups
K = 50 Squats
A = 15 Burpees + 30 Squats

### Joker

Repeat all non-joker cards drawn during the session.

## Features

- Classic Deck mode
- WOD mode
- Editable suit exercises
- Editable face cards
- Workout tracking
- Progressive Web App (PWA)
- Offline support

## Install

### iPhone / iPad
1. Open the hosted app in Safari.
2. Tap Share.
3. Tap Add to Home Screen.

### Android
1. Open the hosted app in Chrome.
2. Tap Install App when prompted.
